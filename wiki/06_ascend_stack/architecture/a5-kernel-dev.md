# A5 算子开发指南

## 一、算子新特性概览

### 1.1 SIMD 新特性

| 特性 | 说明 |
|------|------|
| **指令双发** | 指令有 2 份硬件单元，可并行执行计算指令，硬件自动乱序执行 |
| **RegBase** | 基于寄存器的编程模型，MicroAPI 直接操作 vector 寄存器，减少 UB 搬运 |
| **NDDMA** | 多维数据搬运，搬运时可完成 padding / transpose / broadcast / slice 操作 |

### 1.2 新增 SIMT 编程

- SIMT 更亲和随机访存、小包搬运，离散访存效率高
- SIMD+SIMT 混编：SIMT 处理离散数据，SIMD 处理连续数据
- 每个 AIV 可调用 512~2048 线程

### 1.3 新增 UB 通路

- L1 与 UB 间通路，FixPipe 到 UB 通路
- 减少 CV 融合算子的显存占用和数据传输耗时
- FA 算子在 QKV[8,900,8,64] fp16 下约为 **2.0×A2** 性能

## 二、RegBase 编程指南

### 2.1 RegBase 核心要点

| 要点 | 说明 |
|------|------|
| 寄存器大小 | 256B，LocalTensor 必须对齐至 256B |
| Hardware Loop | RegBase 的 for 循环启动硬件循环，由硬件控制边界和迭代，效率更高 |
| 循环限制 | for 循环最多 **4 层嵌套** |
| 分支限制 | if-else 只能在 for 循环外，**不能用 break 等跳转指令** |
| 依赖控制 | 大部分指令自动分析寄存器依赖，但 **读写读、写读写** 操作需程序员手动控制依赖 |
| Mask 控制 | 通过 maskReg 控制指令计算的数据量 |
| 指令队列 | 深度为 64，需保证队列中有充足的无依赖并发指令 |
| 性能提升参考 | Vector 代码 0.6ms → RegBase 代码 0.1ms（约 **6×**） |

### 2.2 RegBase 优化技巧

#### 显式 Unroll
- 问题：若 RegBase 代码逻辑复杂，有数据依赖的指令超过 64 条，队列无法填满
- 方法：显式 unroll，将无数据依赖的指令重排，充分利用指令双发和乱序执行
- 长短指令局部 unroll：短指令 unroll 提升指令并行度

#### VF 切分
- 问题：不同指令执行耗时有差异，长短指令数据依赖导致计算 bubble
- 方法：强行把长指令和短指令切分到 **两个 VF 函数**中，提高指令并行度

### 2.3 RegBase 代码迁移

- 新增 UB 至寄存器的搬运
- 将整体逻辑用 **MicroAPI** 重写即可完成迁移
- 空间复用：中间变量都在寄存器上处理，节省 UB 空间，可单次处理更多数据

## 三、SIMT 编程指南

### 3.1 SIMT 核心特性

- 每个线程有 **独立控制流**，标量编程，无需感知硬件并行度
- 可访问 GM 和 UB，直接访问 GM 上的数据
- 每个 cycle 只能执行一条指令，以 warp 方式执行
- Scalar 计算效率高，计算 latency 远低于搬运 latency
- 理论访存效率低于 SIMD
- **离散访存亲和**，随机访存 / 小包搬运场景性能优异
- 属于 Vector 流水线，需注意 V 流水同步控制
- 性能提升参考：SIMD 800us → SIMT 120us（约 **6.7×**，离散访存场景）

### 3.2 SIMT 线程配置与寄存器关系

| 配置的最大线程数 | 每个 Thread 可用寄存器个数 | 推荐场景 |
|-----------------|---------------------|---------|
| 1025~2048 | 16 个 | 简单 SIMT 函数 |
| 513~1024 | 32 个 | 中等复杂度（**推荐默认**） |
| 257~512 | 64 个 | 较复杂 SIMT 函数 |
| 1~256 | 127 个 | 复杂 SIMT 函数 |

**注意**：
- 每个 AIV 有 4 个 schedule，控制 warp 队列调度，最多同时执行 128 个线程
- 单 cycle 事务数量有限，访存指令延迟高，ThreadNum 不一定线性提升
- Thread、向量类型、unroll 都涉及寄存器，需联合调优
- SIMT 动态内存大小也会影响性能（3-5%）

### 3.3 SIMT 资源使用建议

- **栈空间**：每个线程栈空间仅 **64B**，单个 SIMT 函数不能写太复杂的程序
- **UB 空间**：SIMT 至少占用 **32KB** UB 空间（算子以 SIMT 为主则分配更多）
- **函数调用**：SIMT 中可调用 `__simt_callee__` 函数，但 **不能调用 VF 函数**

### 3.4 SIMT 优化六大技巧

1. **向量类型优化**
   - 使用 float4、half2 等向量类型合并事务
   - 4 次 float vs 1 次 float4，提高访存效率
   - 要求数据连续

2. **Unroll 展开**
   - 复制循环体代码减少循环迭代次数
   - 提高指令并行度，促进寄存器重用
   - 参考数据：隐式 unroll 193ms → 显式 unroll 165ms

3. **Thread 数量调优**
   - 简单函数：2048 线程
   - 复杂函数：512 或 1024 线程（推荐）
   - 需调试 thread 数量和向量类型以平衡寄存器使用

4. **模板参数优化**
   - 编译期优化代码，将运行时代码变为编译时
   - channel 是 2 的幂次时，可将乘法转为位操作
   - 编译阶段优化分支判断和边界条件

5. **二维线程块**
   - 减少线程内的计算开销
   - 对特征正序遍历，提高 L2 cache 命中率

6. **减少 Warp Divergence**
   - 尽量用 **三元表达式** 替换 if-else
   - 避免分支导致 warp 内线程执行路径不一致

### 3.5 SIMT 适用场景判断（关键经验）

| 场景 | SIMT 表现 | 建议 |
|------|---------|------|
| 点数大，channel ≤ 128B | 优化 **2-4 倍**，channel 越小提升越明显 | **使用 SIMT** |
| 点数小，channel > 128B | 性能 **劣化约 50%** | 使用 SIMD（DataCopy） |

**经验法则**：即使是离散访存，当 channel > 128B 时，SIMD 搬运效率更高（需结合具体场景实验验证）。

## 四、SIMD+SIMT 混合编程

### 4.1 各自优势

- **SIMD**：单个时钟周期完成更多计算指令，UB 访问延时低，擅长连续规整计算
- **SIMT**：每个线程独立访问 GM 任意地址，支持复杂控制流，擅长离散访问

### 4.2 混合编程模式

- SIMD 与 SIMT 函数 **依次执行**
- 两者均可访问 UB 上的 **共享内存** 交换数据
- 同一算子中同时利用两者优势
- 典型模式：SIMT 做离散 gather / 权重计算写 UB → SIMD 做后续连续计算

## 五、CV 融合与 UB 通路

### 5.1 UB 通路优势

- 新增 L1↔UB、FixPipe→UB 通路
- 减少 CV 融合算子的显存占用和数据传输耗时
- 可灵活复用 SIMT 与 RegBase 优化 Vector 和搬运耗时

### 5.2 性能参考

- FA 算子（QKV 均为 [8,900,8,64]，fp16）：A5 约为 **2.0×A2** 性能

## 六、算子优化实战案例

### 6.1 DFA（Deformable Aggregation）算子优化

**算子特点**：
- 6 个 camera + 4 尺度 + 每 anchor 13 个 point 稀疏采样
- 离散访存（采样点稀疏随机）+ 计算复杂（多尺度双线性插值+特征聚合）

**A5 开箱问题**：
- Vec bound，MTE2 占比高（L2 cache 降低导致 MTE2 比 A2 耗时更多）

**优化步骤与效果**：

| 步骤 | 操作 | 效果 |
|------|------|------|
| 1 | RegBase 重构：Channel 维度放最外层 for 循环，减少 Reg 写回频率 | 性能提升 35%，由 Vec bound 转为 MTE2 bound |
| 2 | 显式 unroll：重排无依赖指令，利用指令双发和乱序执行 | - |
| 3 | VF 切分：长短指令分到不同 VF，减少计算 bubble | - |
| 4 | SIMT Scalar 优化：内层 for 循环计算提取到最外层批量 scalar 计算 | 再提升 27% |

**最终经验**：channel=256 较大时，SIMT 搬运数据性能劣化，不如 SIMD（DataCopy）。

### 6.2 SubmSparseConv3dGrad 算子优化

**算子特点**：稀疏 3D 卷积反传，离散访存 + CV 融合

**优化手段**：SIMT 离散访存优化

|------|------|-----------|--------|-----------|
| A2 376T | 523ms | 339ms | 1.0× | - |
| A5 开箱 | 364ms | 307ms | 1.4× | 1.0× |
| SIMT 优化初版 | 210ms | 199ms | 2.5× | 1.7× |
| + 二维线程块 + 正序 | 162ms | 129ms | 3.2× | 2.2× |
| + 向量类型 + unroll | 146ms | 125ms | 3.6× | 2.5× |
